On main page of the project in github press the green button code
and chose downloads zip. extract the zip in your computer.

--- Run In An IDE ----
You can open the entire project with your IDE
You can run it via IDE, or CMD.

For running the tests go to test and run FastestPathTest.py

If you want to add a new graph:
Create a text file which represent your graph .The file should be in the same
format as the other files in the resources directory.
Go to Main class in src/fastest_path and change the input of the FastestPath
constructor to your file name, like this:
path: FastestPath = FastestPath(YOUR_FILE);
